# AP1IA-Agentes-Inteligentes-e-seu-Ambiente
Simulador do ambiente clássico do mundo do aspirador de pó (Russell &amp; Norvig, 2013), feito de forma incremental para a Atividade Prática 1 – *Agentes Inteligentes e seu Ambiente*. Um único programa resolve as quatro etapas: varredura simples, sensores com campo de visão, bateria limitada, e obstáculos com sujeira aleatória.
